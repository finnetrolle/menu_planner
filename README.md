# Menu Planner 🍽️

Кроссплатформенное десктопное приложение для планирования питания и отслеживания нутриентов.

## Описание

Menu Planner — это приложение для планирования рациона с отслеживанием калорий, белков, жиров и углеводов. Приложение позволяет:

- Управлять базой ингредиентов с их нутриентами
- Создавать блюда из ингредиентов
- Планировать рацион с учетом целей по КБЖУ
- Просматривать прогресс достижения нутриентных целей
- Генерировать список покупок

## Технологии

### Frontend
- **React 19** — UI библиотека
- **TypeScript** — типизация
- **Vite** — сборщик модулей
- **Tailwind CSS** — стилизация
- **Radix UI** — компоненты UI
- **TanStack Query** — управление состоянием
- **Recharts** — графики
- **Lucide React** — иконки

### Backend
- **Rust** — основной язык
- **Tauri 2.0** — фреймворк для десктопных приложений
- **SQLite** — база данных (rusqlite)
- **Refinery** — миграции базы данных

## Установка

### Требования

- Node.js 18+
- Rust 1.70+ (с компонентами для вашей платформы)
- Системные зависимости для Tauri (см. [официальную документацию](https://tauri.app/v1/guides/getting-started/prerequisites))

### Шаги установки

1. Клонируйте репозиторий:
```bash
git clone https://github.com/yourusername/menu-planner.git
cd menu-planner
```

2. Установите зависимости frontend:
```bash
npm install
```

3. Соберите Rust зависимости:
```bash
cd src-tauri
cargo build
cd ..
```

## Разработка

### Запуск в режиме разработки

```bash
npm run tauri dev
```

Эта команда запустит:
- Vite dev сервер для frontend
- Tauri backend в режиме hot-reload

### Сборка для продакшена

```bash
npm run tauri build
```

Приложение будет собрано в `src-tauri/target/release/bundle/`

## Архитектура

### Backend

Приложение использует слоистую архитектуру:

1. **Commands** — Tauri commands, доступные из frontend
2. **Services** — бизнес-логика (расчеты нутриентов, валидация)
3. **Repositories** — доступ к данным (CRUD операции)
4. **Models** — доменные модели

### Frontend

- **TanStack Query** для управления состоянием сервера
- Компоненты используют Tauri API через инвок команды
- Radix UI для доступных и кастомизируемых компонентов

## База данных

### Схема

```sql
ingredients           -- Ингредиенты
dishes                -- Блюда
dish_ingredients      -- Связь блюд и ингредиентов
goals                 -- Цели по нутриентам
```

### Начальные данные

В каталоге `data/` находятся:
- `ingredients.sql` — 80 ингредиентов с нутриентами
- `dishes.sql` — 20 блюд с ингредиентами

## Расчет нутриентов

Приложение использует правило 4-9-4:
- 1г белка = 4 ккал
- 1г жира = 9 ккал
- 1г углеводов = 4 ккал

## Сценарии использования

### 3-шаговый планировщик меню:
1. **Ввод целей** — задать желаемые значения КБЖУ
2. **Выбор блюд** — добавить блюда в меню с реальным расчетом нутриентов
3. **Результаты** — просмотр плана и списка покупок
