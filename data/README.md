# Data Directory

Эта директория содержит данные, экспортированные из существующего приложения `menu_app` для использования в качестве начального набора данных для SQLite.

## Файлы

| Файл | Формат | Описание |
|------|--------|---------|
| `ingredients.json` | JSON | 80 ингредиентов с КБЖУ |
| `dishes.json` | JSON | 20 блюд с их ингредиентами |
| `ingredients.sql` | SQL | SQL INSERT statements для ингредиентов |
| `dishes.sql` | SQL | SQL INSERT statements для блюд |

## Статистика

### Ингредиенты: 80 штук
- Мясо и рыба: говядина, курица, свинина, минтай, тунец
- Крупы и макароны: гречка, рис, лапша, спагетти
- Молочные продукты: молоко, сливки, йогурт, творог, сметана
- Овощи: картофель, морковь, лук, свекла, капуста и др.
- Масла: сливочное, подсолнечное, оливковое, кунжутное
- Соусы: соевый, майонез, горчица, томатная паста
- Фрукты: банан, яблоко, апельсин
- Другое: яйца, специи, зелень

### Блюда: 20 штук
- Основные блюда: Чашушули, Щи, Лапша с курицей, Греча с молоком
- Салаты: Окрошка, Оливье, Винегрет, Мимоза тунцовая
- Гарниры: Картофель фри, Овсяная каша, Паста Барилла
- Перекусы: Куриное филе, Минтай, Вареное яйцо
- Напитки: Кофе с молоком
- Фрукты и сладости: Банан, Яблоко, Мармеладка
- Спортивное питание: Протеин

## Использование

### Для SQL импорта (рекомендуется для SQLite)

```bash
# Создать таблицы (см. schema.sql в проекте)
# Затем импортировать данные
sqlite3 menu_planner.db < data/ingredients.sql
sqlite3 menu_planner.db < data/dishes.sql
```

### Для JSON импорта (для Rust)

```rust
// Десериализация JSON файлов
let ingredients: Vec<Ingredient> = serde_json::from_str(include_str!("data/ingredients.json"))?;
let dishes: Vec<DishWithIngredients> = serde_json::from_str(include_str!("data/dishes.json"))?;

// Вставка в базу данных
for ingredient in ingredients {
    repo.create(&ingredient)?;
}
```
