## Why

На экране управления блюдами сейчас есть только поиск по названию и карточки без дополнительных средств навигации. Когда список блюд вырастает, пользователю становится неудобно быстро находить нужные позиции, сравнивать блюда по КБЖУ и отбирать подходящие варианты под конкретную задачу.

## What Changes

- Добавить на страницу управления блюдами управляемую сортировку списка.
- Поддержать несколько вариантов сортировки, включая название, вес, калории и макронутриенты.
- Добавить фильтрацию, чтобы пользователь мог быстро сузить список блюд по поиску и пищевым характеристикам.
- Сохранить текущую клиентскую модель расчёта КБЖУ и встроить новые элементы управления без изменения существующих CRUD-потоков блюд.

## Capabilities

### New Capabilities
- `dish-list-navigation`: удобная навигация по каталогу блюд через сортировку, фильтрацию и просмотр вычисляемых КБЖУ на экране управления блюдами.

## Impact

- Затронутый frontend-код: [src/pages/DishesPage.tsx](/Users/finnetrolle/dev/menu_planner/src/pages/DishesPage.tsx), потенциально общие UI-компоненты ввода и кнопок сортировки.
- Источник данных не меняется: список блюд продолжит загружаться через `useDishes`, а КБЖУ будут вычисляться на клиенте на основе `useIngredients` и `calculateCalories`.
- Backend и схема БД не требуют изменений, если сортировка и фильтрация останутся на клиенте.
